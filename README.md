# Asteroid Miner

A short game you play in the terminal. You steer a ship across a 10 × 10
asteroid field with W, A, S and D, collecting minerals (iron, gold and crystal)
on your way to the goal. Each move uses one unit of fuel. Reaching the goal wins
the game, and running out of fuel first loses it. All it needs is Node.js 18 or
newer: no installation, account or internet connection.

## Run the game

From the repository root:

```bash
npm start
```

## Run the tests

From the repository root:

```bash
npm test
```
